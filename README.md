# Telegram DevOps / SRE / Intern Monitor

Python-скрипт для мониторинга Telegram-каналов и поиска постов по ключевым словам.

Проект отслеживает заданные Telegram-источники, проверяет новые и последние опубликованные посты, ищет в них ключевые слова вроде `DevOps`, `SRE`, `Intern`, `Системный администратор`, а затем отправляет подходящие посты в выбранный Telegram-чат, группу или в «Избранное».

---

## Возможности

- Мониторинг нескольких Telegram-каналов
- Поиск постов по ключевым словам без учёта регистра
- Проверка последних постов при запуске скрипта
- Отслеживание новых постов в реальном времени
- Отправка найденных постов в выбранный Telegram-чат
- Добавление ссылки на оригинальный пост
- Отображение источника в формате `@channel`
- Защита от повторной отправки уже обработанных постов
- Хранение обработанных постов между перезапусками
- Настройка через `.env`
- Обработка Telegram flood-limit ошибок

## Как работает проект

1. Скрипт загружает настройки из `.env`
2. Подключается к Telegram через Telethon
3. Читает список каналов из `SOURCE_CHATS`
4. При запуске проверяет последние несколько постов в каждом канале
5. После этого продолжает слушать новые публикации
6. Каждый пост проверяется на наличие ключевых слов
7. Если совпадения найдены, бот отправляет сообщение в `TARGET_CHAT`
8. ID обработанных постов сохраняются в `processed_messages.json`
9. При следующем запуске уже обработанные посты не отправляются повторно

Защита от дублей

Бот сохраняет обработанные посты в файл:

processed_messages.json

Ключ поста строится по принципу:

channel_id:message_id

Например:

-1002538491450:96

Если бот уже видел такой пост, он не отправит его повторно.

Важно: история дублей не зависит от TARGET_CHAT. Если пост уже был обработан при отправке в me, то при смене получателя он не будет отправлен повторно.

Чтобы сбросить историю обработанных постов:

rm processed_messages.json

После этого бот снова проверит последние посты и отправит подходящие.

Ограничения
Скрипт должен быть запущен, чтобы ловить новые посты в реальном времени
Если компьютер выключен, бот не слушает новые события
При запуске бот дополнительно проверяет последние несколько постов в каждом источнике
Для приватных каналов аккаунт должен иметь доступ к каналу
Telegram может временно ограничить отправку сообщений при слишком частой рассылке
Ссылки на посты формируются только для публичных каналов с username
Основные настройки в коде

В main.py есть параметры:

RECENT_POSTS_LIMIT = 5
SEND_DELAY_SECONDS = 10

RECENT_POSTS_LIMIT — сколько последних постов проверять при запуске.

SEND_DELAY_SECONDS — пауза между отправками сообщений, чтобы не упереться в лимиты Telegram.
